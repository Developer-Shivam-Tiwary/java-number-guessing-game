# 🎯 Number Guessing Game | Java CLI Project

A simple **Number Guessing Game built using Core Java** to practice problem-solving, logical thinking, and programming fundamentals. The game challenges players to guess a randomly generated 4-digit number between 1000 and 9999.

This project is part of my **Practicing Problem-Solving & Logic Building** series.

- 🎯 Guess a randomly generated 4-digit number.
- 🔢 Number range: 1000–9999.

## ⚙️ How to Run

### Option 1: Run Online

1. Open the project on JDoodle.
2. Run the Java program.
3. Enter your guess when prompted.
4. Follow the game instructions.

### Option 2: Run Locally

1. Install Java JDK on your system.
2. Save the source code as `NumberGuessingGame.java`.
3. Open a terminal in the project directory.
4. Compile and execute:

```bash
javac NumberGuessingGame.java
java NumberGuessingGame
```
